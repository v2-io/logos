## §0 — How to use this file (the deposit discipline)

Each essay, when it lands a structural move, **deposits** it here as a registry entry (§3): a one-line pointer to
where it is *argued*, what it *requires* to stand, its *grade*, and any *flag* (a braid to un-braid, a rival to
distinguish, a balance still owed). Arguments are never written out here — only their coordinates and their load
conditions. That is what keeps the ledger operational without letting it harden into a false outline. Read order
for someone picking this up cold: §3 (what's been found and what's owed) → §1 (the taxonomy it rests on) → §2
(which axes are carrying weight) → §4/§5/§6.
